🎨 Whispered Strokes – Art Portfolio by Sab

Whispered Strokes is a fully responsive, four-page art portfolio website created to showcase my artwork and my journey as both an artist and a frontend developer.
This project blends elegant UI design, custom CSS styling, and advanced JavaScript functionality to create an interactive, personal, and immersive art experience.

📌 Project Summary

Whispered Strokes is built to function as a digital art portfolio and the foundation of my future online art store.
It includes:

A beautiful homepage showcasing curated artworks

An About page sharing my artistic journey

A fully interactive Collections page

A contact page with live form submission

A complete cart + filter system powered by JavaScript

A slide-in sidebar cart with animations

Clean typography, responsive design, and consistent theme

🎨 Collections Page (Core Functionality)

This is the heart of the website and includes:

🔍 Dynamic Filter System

Filters artworks by category:

Watercolor

Acrylic

Charcoal

Pencil Sketches

Instant hide/show using JavaScript

No page reload

Active button highlighting

🛒 Add-to-Cart + Quantity System

Increment and decrement quantity

Prevents adding 0 items

Handles duplicate items correctly

Real-time quantity and price updates

Green button feedback for successful addition

📦 Slide-In Sidebar Cart

Opens when clicking the cart icon

Smooth sliding animation

Contains all cart items dynamically

Auto updates when adding items

Close button to hide sidebar

This entire system is powered by modular, clean JavaScript using:

DOM queries

Event listeners

Template literals

Array methods: .find(), .forEach()

A centralized updateCart() function

☎️ Contact Page

Responsive contact form

Web3Forms integration (live backend)

Name, email, message fields

Beautiful right-side info panel

Displays address, phone, email, and logo

🚀 How to Run the Project

You can run the portfolio on any device:

Download or clone the repository

Make sure the file structure is correct

Open home.html in the browser

Interact → Filters, add-to-cart, sidebar cart, forms

No installation or setup required.
